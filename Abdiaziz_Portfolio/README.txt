ABDIAZIZ PORTFOLIO
==================

Files:
- index.html
- style.css
- script.js
- assets/ (your uploaded images)

How to run:
1. Open the folder in VS Code.
2. Open index.html with Live Server, or double-click index.html.
3. Edit your text/social links in index.html if needed.

The profile photo has an animated rotating ring around it.
The portfolio images are displayed in the Portfolio section.
